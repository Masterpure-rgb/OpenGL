# Компьютерная графика. Модуль 2. Графическая библиотека OpenGL

Интерактивные материалы к методическим указаниям к лабораторным работам (Ф.М. Нуралиев, С.Н. Ибодуллаев; ТУИТ имени Мухаммада аль-Хорезми, 2026).

Сайт: **https://masterpure-rgb.github.io/OpenGL/**

- **Лабораторные работы 1–5** — для каждой: аудиообъяснение темы (`/e/N/`), лаборатория с кодом C++/freeglut, который выполняется прямо в браузере и проверяется автоматически (`/l/N/`), контрольные вопросы и варианты индивидуальных заданий (`/z/N/`). Прежние адреса `/l/11/` … `/l/15/` перенаправляют на новые.
- **СРС 1 и СРСП 1–3** — `/srsp/`.
- **Методические указания (Word)** — `metodichka/OpenGL_laboratornye_raboty_2026.docx`.
- **Песочница** — свободный редактор OpenGL (`/sandbox/`).
- **Сдача работ** — через [Issues](../../issues) этого репозитория (форма «Сдача работы»), инструкция — `/help/`.
- **Мой кабинет** (`/me/`) — посещаемость и статусы работ студента; **панель преподавателя** — `/admin/`.

Журнал хранится в `data/` в зашифрованном виде (AES-GCM): `data/journal.json` — ключ из пароля преподавателя, `data/s/*.json` — карточки студентов, ключ из ID и кода доступа.

## Как устроена браузерная среда

`assets/js/cpp.js` переводит подмножество C++ в JavaScript, `assets/js/gl1.js` реализует OpenGL 1.5, GLU и GLUT поверх WebGL2 (фиксированный конвейер: освещение, материалы, текстуры, туман, трафарет, накопительный буфер, дисплейные списки, массивы вершин, VBO). Тот же код компилируется в Visual Studio 2022 с freeglut.

Данные чайника Юта — из freeglut (MIT). Парсер `assets/js/vendor/acorn.min.js` — Acorn (MIT). Текстуры в `assets/tex/` сгенерированы процедурно.
